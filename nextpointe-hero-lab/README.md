# NextPointe Hero Lab

Disposable visual playground for the NextPointe hero. It does not modify the production NextPointe website.

Current source model:
- GHL-hosted STL: https://assets.cdn.filesafe.space/mhYINaszQSh466H9YX6C/media/6ac10263c478ac55359dc483.stl

The STL preserves geometry but not the original GLB materials/textures, so the current Three.js demo recreates the surface with a green PBR material and studio lighting. Replace the model URL/loader with GLB when the original GLB is publicly hosted.
